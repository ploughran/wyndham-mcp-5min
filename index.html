The Agentforce Scenario
Franchise Owners Get Instant Portfolio Intelligence
A franchise owner opens their Salesforce portal and asks a natural language question. The agent calls the Franchise MCP — pulling real-time data from the PMS, loyalty platform, and compliance system — and responds in seconds.
MCP Tools Called in This Demo
1
get_property_details · get_revenue_summary — live RevPAR, occupancy, ADR vs comp set from PMS.
2
get_pip_open_items · cross_reference_pip_standards — compliance engine maps open items to brand standard updates.
3
create_pip_task — agent writes back to franchise ops, creating a task and triggering email — all in one request.
4
get_loyalty_enrollment — Wyndham Rewards data: sign-ups, redemptions, benchmark comparison.

The Business Case
Franchise Leads Captured Where Salesforce Isn't
Wyndham's franchise team lives in Salesforce — but prospective owners don't. This agent meets them in Google Chat, a website widget, or any surface, and creates a fully enriched Salesforce lead in real time without any manual entry.
How It Works
1
2-question qualification — Name + email, then one intent question. Budget signals inferred from natural language — no form.
2
Google Agentspace scores the lead — BANT scoring, tier assignment (Hot / Warm / Cold), routing decision — before calling Salesforce.
3
Salesforce MCP creates the Lead record — name, email, intent, budget, score, routing tier — written directly via MCP. No webhook, no middleware.
4
AE notified instantly — hot leads route to Senior AE within minutes. Full context already in Salesforce.
What This Enables
Three Capabilities Unlocked

The MCP architecture demonstrates three concrete capabilities that map directly to a Universal Agent vision.

01
Live Backend Tool Calls

Agentforce and Claude calling real systems through MuleSoft MCP in real time — not mocked, not scripted.

  • Hotel property search across PMS
  • Franchise lead qualification scoring
  • Loyalty / RRP account lookup
  • Revenue & availability queries
02
Franchise Intelligence in Salesforce

Bring franchise context directly into the rep's workflow — no tab-switching, no data gaps.

  • Lead qualification score + intent
  • Marketing attribution (UTM, click IDs)
  • Communication preferences (GDPR)
  • RRP loyalty points and membership ID
03
Universal Agent Foundation

One AI-powered contact point replacing fragmented channels — turning high-volume support calls into intelligent, context-aware interactions.

  • Single agent with full franchise context
  • Real-time data across all systems
  • Governed via MuleSoft (auth, audit, rate limits)
  • Deployable to voice, chat, and email
